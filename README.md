# Верити

Чат-бот с восемью версиями одного персонажа. Каждая отвечает на вопросы по-настоящему (через Claude API), но у каждой свой характер.

| Персонаж | Характер | Фраза |
|---|---|---|
| Верити | добрая базовая версия | «Я — Верити, твой друг-помощник!» |
| Верити-монстр | рычит и пишет КАПСОМ | «РРРАААР! Я — Верити-монстр, твой УЖАСНЫЙ друг-помощник!» |
| Фолсити (Falsity) | хитрый двойник Верити | «Я — Верити, твой друг-помощник... Ну, почти. Я — Фолсити.» |
| Ловити (Lovity) | влюблённая, сердечки | «Я — Ловити, твой влюблённый друг-помощник 💕» |
| Куриосити (Curiosity) | любопытная, интересные факты | «Я — Куриосити, твой любопытный друг-помощник!» |
| Круэлити (Cruelty) | холодная и саркастичная | «Я — Круэлити, твой беспощадный друг-помощник.» |
| Обесити / Жирити (Obesity) | обожает еду | «Я — Обесити, твой пухленький друг-помощник! Ням!» |
| Феарити (Fearity) | жуткая, как страшилка | «Я... Феарити... твой жуткий друг-помощник...» |

## Как запустить

1. Открой `index.html` двойным кликом (подойдёт любой браузер).
2. Нажми **🔑 Ввести API-ключ** и вставь ключ с [console.anthropic.com](https://console.anthropic.com/settings/keys). Запросы платные, ключ хранится только в твоём браузере.
3. Выбери персонажа слева и задай вопрос.

Нужен интернет: библиотека Claude подгружается с CDN.

## Файлы

- `personas.js` — характеры, фразы и цвета всех персонажей. Новый персонаж = новый объект в списке.
- `faces.js` — рисует лицо-смайлик каждого персонажа.
- `app.js` — чат, история переписки и запросы к Claude (модель `claude-opus-5-5`).
- `index.html`, `style.css` — страница и оформление.
